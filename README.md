# Collec Desktop — Releases

Installers for the [Collec](https://collec.ai) desktop app. This repository holds **release assets only**; the application source is maintained in a private repository.

**Download:** https://collec.ai/en/download (picks the right build for your OS)

| Platform | File |
|---|---|
| Windows 10+ (x64) | `Collec-win-x64.exe` |
| macOS 12+ (Apple Silicon) | `Collec-mac-arm64.dmg` |
| macOS 12+ (Intel) | `Collec-mac-x64.dmg` |
| Linux (x86_64) | `Collec-linux-x64.AppImage` |

Latest build of each file: `https://github.com/SOMA-Corporation/collec-desktop-releases/releases/latest/download/<file>`

Builds are not code-signed yet — Windows SmartScreen / macOS Gatekeeper may ask you to confirm before opening.

Issues and feedback: https://collec.ai/en/contact-us
